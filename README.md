Costa Alba is an original open-world crime game: a sun-soaked coastal city you explore on foot and by car, with traffic and pedestrians, cars to steal, a wanted level with police chases and a helicopter, nine story missions, combat, a HUD with a minimap, a start screen, saves and synthesized radio music.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD to move and drive, mouse drag for the camera, click to shoot, E to enter or steal a car, M to start the next mission, R to change the radio station, Esc to pause.
